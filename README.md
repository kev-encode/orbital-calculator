# **Orbital Calculator**

An interactive satellite orbit visualizer app.

<br>

## **Table of Contents**

1. [Prerequisites](##prerequisites)
2. [Installation](##installation)
3. [Features](##features)

<br>

## **Prerequisites**

* Python 3.12.10
* Pip (Python package manager)

<br>

## **Installation**

1. Set up virtual environment, enter, and install requirements.

    **Windows**

    ```bash
    python -m venv .venv
    .\.venv\Scripts\activate
    pip install -r requirements.txt
    ```

2. Run app.

    ```bash
    python .\src\main.py
    ```

<br>

## **Features**

* Input planet mass
* Input planet radius
* Input orbite height from ground
* Planet orbit presets
    * Sun, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune
* Orbit period calculation
* Orbit speed calculation
* Zoom in/out
* Dynamic scale 
* Orbit and celestial body visual
