## **Prerequisites**

* Python 3.12.10
* Pip (Python package manager)

<br>

## **Installation**

1. Set up virtual environment, enter, and install requirements.

    **Windows**

    ```bash
    python -m venv .venv
    .\.venv\Scripts\activate
    pip install -r requirements.txt
    ```

2. Run app.

    ```bash
    python .\src\main.py
    ```
